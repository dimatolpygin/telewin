# Проект telewin — «Домашний мастер»

База знаний по проекту. Клиент: telewin (сеть хозяйственных магазинов «Домашний мастер», masterberez.ru).

## Что делаем

Комплексная автоматизация на 3 этапа. Сейчас в работе **Этап 1: прайс + чат-боты VK и MAX** — покупатель пишет боту название товара, бот отвечает наличием (по двум магазинам) и ценой из товароучётной программы «Мемо Фора».

## Запуск (разработка)

Нужны только Docker и Docker Compose — Node на хосте не обязателен.

```bash
cp .env.example .env   # заполнить значения, пароль Postgres придумать любой
docker compose up -d --build
curl http://localhost:3000/health
```

Поднимаются три контейнера: `telewin-app`, `telewin-postgres`, `telewin-redis`.
Миграции применяются автоматически при старте app. Правка в `src/` перезапускает
приложение сама, пересобирать образ не нужно.

Полезное:

```bash
docker compose ps                 # статусы и healthcheck
docker compose logs -f app        # логи приложения (на русском)
docker compose down               # остановить
docker compose down -v            # остановить и стереть данные БД
npm run db:generate               # создать миграцию после правки src/db/schema.ts
```
