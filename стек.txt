## Стек (согласовано)
- **Node.js LTS + TypeScript**, HTTP — **Fastify**, Telegram-обкатка — **grammY**.
- **Postgres 16** (Docker, отдельная схема под проект) + **Redis** (память диалога, очереди/дебаунс, лиды).
- **Drizzle ORM + drizzle-kit** — миграции (аналог alembic), автоприменение в entrypoint контейнера перед стартом app.
- **tsx watch** — авто-пересборка при изменениях (в Docker: volume mount + watch).
- **pino** — полный слой логов (см. ниже), на русском, каждое действие.
- ИИ — **OpenRouter**, модель `anthropic/claude-haiku-4.5` (id `claude-haiku-4-5-20251001`), temperature ~0.8, function calling.
- Веб-панель — **своя SPA (Vite + React + shadcn/ui)**, НЕ AdminJS (упрёмся в кастомизацию промпта/статистики).
- Всё в Docker (app + postgres + redis), CI/CD — GitHub Actions.


## Полный слой логов (pino, «каждая щель»)
Логировать: каждое входящее/исходящее сообщение; каждый tool-call (имя+аргументы+результат);
каждый вызов ИИ (модель, латентность, токены, при отладке — промпт/ответ); каждый запрос к Avito/amoCRM
(метод, статус, тело при ошибке); склейку/дебаунс, прерывания, лиды, ошибки с контекстом; request-id через весь путь.
